# Exact-machine source intake

Nothing in this directory is packaged into the app. Keep each original SVG and its provenance
here so the reviewed Kotlin geometry can always be traced back to the supplied drawing.

For each machine, provide:

- the original, unflattened SVG;
- manufacturer and exact model as printed on the machine;
- manufacturer manual URL or PDF;
- clear side and front reference photos of the actual gym machine;
- the name or role of the trainer or machine maintainer reviewing the guide;
- the review date and any machine-specific setup limits.

Pilot filename: `leg-press.svg`. Do not add a production `machine_guides.json` entry or geometry
implementation until every item above is present. Never substitute a visually similar model.
